## D. 해결되지 않은 운영 항목과 근거

1. **실제 전체 수집 성공 미확인.** 기존 인증정보로 KE·LJ·7C 게시 없는 dry-run을 실행했으나 KE timeout, LJ 수집 실패, 7C HTTP 403, Anthropic HTTP 400 잔액 부족으로 exit 1/HOLD였다. 공개 JSON 7개 SHA256은 전후 동일했다. [실행 결과](review-evidence/live-pipeline.json), [민감값을 제거한 실제 로그](review-evidence/live-pipeline.log). 충전·계정 변경·재실행은 하지 않았다. 이후 실패 파서 생략 수정은 주입된 파서 회귀로 검증했다.
2. **광고 정책·CMP 및 운영 분석 계정 확인 필요.** 광고 기본값 false, Clarity ID 공란을 유지한다. GA4 DebugView 실수신·Clarity 세션·AdSense 노출·동의 철회의 외부 서비스 결과·MyRealTrip 매출/수수료는 확인하지 못했다. 로컬 이벤트/로더 검사는 외부 수신 증명이 아니다.
3. **배포 환경 및 외부 CI 미검증.** Vercel 연결 식별 파일은 있지만 실제 배포·환경 변수 변경은 하지 않았다. 로컬 커밋에 대한 GitHub 상태 조회는 Ref not found였고 이번 변경도 push하지 않았다. CI 정의 연결과 외부 실행 성공을 구분한다.
4. **현재 운영 canonical 불일치 잔존.** 읽기 전용 live 검사의 실패는 기록 그대로 보존한다. 로컬 URL 검사의 성공으로 운영 수정 완료를 주장하지 않는다.
5. **과거 메타데이터 누락 잔존.** 경고 수는 금액 오류 수가 아니다. 원문 스냅샷 없는 과거값은 최신 확정 비교·최저액·신규 공시 배지의 근거에서 제외한다. 과거 페이지의 모든 뉴스·시장 수치까지 사실 검증한 것은 아니다.
6. **실측 Core Web Vitals 미확인.** 로컬 브라우저의 LCP/`cls` 표본은 외부 요청을 막은 합성 측정이다. `cls`는 약 1.8초 동안 입력 없는 이동 점수의 합이며 표준 세션 윈도 기반 운영 CLS가 아니다. 최초 표본에서 항공사 목록 0.369, 전망 0.332의 이동이 관찰돼 숨김 패널의 지연 CSS를 보완했다. 최종 로컬 표본도 항공사 목록 0.369, 전망 0.203으로 0이 아니었다. 항공사 목록의 로딩→9개 행 교체와 상태 표시줄·후속 렌더러의 높이 변화는 남는다. 전체 렌더러 재작성 없이 이 검수에서 모두 제거하지 않았고 속도·CWV 합격 판정을 하지 않는다. 운영 사용자 분포·INP·모바일 네트워크·광고 영향·검색 색인·AI 검색 노출을 증명하지 않는다.
7. **다국어 범위.** 원문 검증 집계와 주요 공시·SEO 문구는 6개 언어를 회귀 검사했다. 신규 계산기 상태·저장 UI 일부는 기존 구현대로 한국어/영어를 제공하며 나머지 언어 선택 시 영어로 표시된다. 전체 UI의 6개 언어 번역을 완료했다고 주장하지 않는다.
8. **단계·MOPS 공식 원문 추가 확인 필요.** 보관 시장 기록의 11월 27단계 및 MOPS 173.89 USD/bbl·414.03 cents/gal은 이번 공시 금액표 대조만으로 확인되지 않는다. 최신 뉴스·전망에서는 원문 대조된 금액과 이 시장 기록을 분리했다. 기존 모든 단계·시장 가격·뉴스를 사실 검증한 것은 아니며, 새 공식 근거 없이 공시 금액에서 단계를 역산하지 않았다.

## E. 운영과 유지관리

```text
npm run verify:release
node scripts/sync_static_snapshots.cjs --write
npm run check:deployment
```

첫 명령이 통합 읽기 검증이다. 원문 검토와 렌더러 변경 후 둘째 명령으로 로컬 HTML을 갱신하고 diff를 검토한 뒤 첫 명령을 다시 실행한다. 셋째 명령은 운영 검토 상태만 확인하며 현재 의도적으로 실패한다. 운영 상태를 임의로 reviewed로 바꿔 우회하지 않는다. CI는 검증 로그를 artifact로 보존하며 테스트 실패는 배포 빌드 실패로 연결된다.

추가 패키지·상시 운영비는 없다. 검증 스크립트가 빌드 시간과 CI artifact 저장량을 늘리지만 일반 방문자의 외부 요청은 추가하지 않는다. 원문별 검토 스냅샷은 추후 공시마다 갱신해야 하는 의도적인 운영 업무이며 완전 무인 수집을 주장하지 않는다.
